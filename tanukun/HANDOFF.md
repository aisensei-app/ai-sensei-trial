## 2. ファイルの役割

| ファイル | 中身 |
|---|---|
| `config.js` | 絵のファイル名、さわる範囲（zones）、揺れの設定（bellyJiggle / chestJiggle）、なかよし度の設定など |
| `lines.js` | セリフ集。条件（場面・場所・気分・時間帯・なかよし度・連続日数・来かた）で出し分け。`{name}` で呼び名 |
| `save.js` | 記録（何日目・連続日数・なかよしポイント・遊んだ回数・見たセリフ・呼び名）。ブラウザ内（localStorage）だけに保存 |
| `belly.js` | おなか・胸の「ぷるん」。メッシュ変形（絵を網目状に変形）＋ばねの計算 |
| `app.js` | 動きの本体（タップ、気分、怒る→隠れる→戻る、メニュー、名前登録、実績・設定、お試し版の診断） |
| `demo.js` | お試し版の設定（診断結果4種類、ポスト文、ハッシュタグ、フォローするアカウント） |
| `tools/build_demo.py` | お試し版の公開用ファイル一式（demo-dist）をつくる |
| `tools/build_preview.py` | 確認用リンク（Artifact）用の1ファイル版をつくる |
| `images/` | 絵（720×900、背景透過の WebP）。元はマゼンタ背景で受け取り、透明化済み |

## 3. 本編（スマホ版）でできていること

- **メニュー画面**：「なかよし ○日目」（のべ日数・大きく）、「れんぞく ○日」（2日以上で小さく）、遊ぶ（横にハート💖）・実績・設定
  - 日付は **午前4時** に切り替え
  - なかよしポイント：その日はじめて来ると +10、タップ1回 +1（1日20まで）。ハート5段階 `heartAt: [10, 50, 120, 220, 360]`
- **はじめて開いたとき**：タヌくんが「なんて呼んだらいい？」と聞く（スキップ可・設定から変更可・10文字まで）
  - 名前なしのときは、セリフの `{name}、` ごと消える（「ユーザーさん」とは呼ばない方針）
  - ハートが増えるほど、名前入りのセリフが出やすい
- **さわる場所**：頭・むね（左右）・おなか・しっぽ
  - 頭：続けてなでると「とろける」
  - おなか：**Windows版と同じ方式**（メッシュ変形＋ばね SPRING=450, DAMP=9）。指を置くとへこみ、指の位置にくぼみと薄い影（押した感）。はなすと「ぷるん」。すべらせると引っぱれる。「ぽん！」「ぽこ！」の文字
  - むね：おなかと同じ方式で控えめ（gain 0.45）。**上下にぷるんぷるん揺れる**（bob 1.4）。**引っぱりは無効**（小さい範囲を引っぱると形が崩れたため）
  - 胸の揺れの中心は、ユーザーがマス目で指定した **21番・26番**（720×900 の絵で (140,320) と (340,320)）。範囲は胸のふくらみ全体
- **気分**：短時間にたくさんさわると 照れ → 困り → 怒る（茂みに隠れる → 戻ってくる）
- **きせかえ（2026-10-25 追加）**：メニューの「きせかえ」から部品を付けはずしできる（アバターのような仕組み）
  - 部品は `config.js` の `parts` に、場所（slot）ごとに登録。1つの場所に1つだけ付けられる
  - いまある部品：おへそ →「デベソ」（`images/parts/debeso.webp`、中心 (192,461)、横幅 56px）
    - 絵は、ユーザーが見せてくれた別キャラの絵を参考にした **日本の漫画風**（丸いでっぱり＋細い輪郭線＋まんなかに「×」）
    - `tools/make_debeso.py` でプログラムで描いている（色・大きさは中の数字で調整）。ユーザーの絵ができたら差し替えてもよい
    - おへその位置は、どの表情の絵でも同じだったので、位置の指定は1か所で済む
  - しくみ：ふだんは `#parts-layer` に `<img>` を重ねて表示。さわって揺れている間は、
    `belly.js` が **元の絵＋部品を合成してから網目の変形** をするので、部品もいっしょに「ぷるん」と揺れる・へこむ
  - 部品ごとに `hearts`（なかよし度で解放）と `hideOn`（出さない絵。省略時は茂み）を設定できる
  - 位置を書かない部品は「720×900 の透明な絵全体」として重ねる（絵を描く人には、この方式がいちばん楽）
  - 選んだ部品は記録の `wear` に保存。付けはずしするとセリフ（`lines.js` の scene: 'wear'、part: 部品の id）
  - お試し版では部品を使わない（`build_demo.py` で images/parts も外す）
  - PC でファイルを直接開く簡易方式（file://）では、部品は揺れずに止まったまま
- **おまた（2026-10-25 追加）**：なかよし度（ハート）で反応が変わる。設定は `config.js` の `crotch`
  - ハート0〜1：1回目は怒り顔で「次さわったら怒るからね！」と注意だけ。10秒以内にもう一度さわると怒って隠れる（`crotch.warnSeconds`）
  - ハート2〜3：モジモジ（照れ顔＋小さくくねくね）。1回を2回分と数えるので、続けると怒る
  - **しっぽだけが「ビクン」と跳ねる**（2026-10-26）。網目の変形で、付け根を軸にしっぽを回す
    （付け根は動かず、先ほど大きく動く。`crotch.tail`。モジモジ・デレ・デレ2の絵はしっぽの位置がほぼ同じ）
    - 角度：モジモジ 10°、デレ 5°（控えめ）、デレ2 10°（`crotch.tail.angles`）
  - ハート4〜：デレる（とろけ顔・照れ顔。1回を0.5回分と数える）
  - ハート5：デレに加えて、腰みのの前が **3.5秒だけ「むくっ」とふくらむ**（網目の変形で、まんなかの葉っぱを拡大＋丸く見せる陰影＋少し持ち上げ）
    - 強さは `crotch.bulge` の amount（0.35 まで）・shade（陰影）・lift（持ち上げ）。2026-10-26 にユーザーの希望で強めた（0.18 → 0.32＋陰影）
    - 範囲は「腰みのの前のまんなかの葉っぱの中だけ」にしぼった（太ももがふくらんでいたため。デレ2の絵で中心 (235, 600)）
    - ふくらんでいる間にさわると「ぷるん」と揺れる（`crotch.bulge.poke`）
  - 方針：**センシティブにならないギリギリ**。ふくらみは「気づく人は気づく」程度。表示は腰みのの上からだけ
  - 範囲：zones.crotch（腰みのの前。おなかと少し重なるが、おまたが優先）。ヒントの文には書かない（隠し要素）
  - お試し版（X で公開中）には入れていない（`demo.js` で外す）
  - 専用イラスト（2026-10-26）：`images/mojimoji.webp`（両手で腰みのの前を押さえる・困り赤面）、`images/dere.webp`（胸の前で指ちょんちょん・横目の照れ顔）
    - ChatGPT で作成（これまでのチャットの続き。「通常」の絵＋設定画を添付し、表情・ポーズだけ変える指示文）
    - モジモジは、手と手のすき間に出ていたピンク色の部分（きわどく見えるため）を、葉っぱの色で塗りつぶし済み
    - この2枚は体が少し右に寄っているので、デベソの位置を絵ごとに指定（`parts` の `faces`）
    - `images/dere2.webp`（目を閉じて照れ笑い・腕を腰の後ろ）：ハート5でふくらむときの絵。
      1回目は正面向き・足を広げていてNG → 「デレの絵を土台に、表情と腕だけ変える」頼み方でうまくいった
    - ふくらむ場所はデレ2の腰みのに合わせた（ふくらんでいる間はデレ2の絵のまま）
  - 新しいポーズの絵の取りこみ：`tools/make_pose.py`（マゼンタ背景の透明化＋腰から下で「通常」の絵に自動で位置合わせ）
- **絵の色味をそろえた（2026-10-26）**：ChatGPT で1枚ずつ描いたため、絵ごとに色が違い、表情が切りかわると
  「色が薄くなる」ように見えていた（特に「通常」が、赤み寄り・あざやかさ低めでくすんでいた）
  - `tools/match_colors.py`：体（肌と毛）の「色合い・あざやかさ・明るさ」を、全部の絵の平均にそろえる
  - **新しい表情の絵を足したら**：make_pose.py で取りこむ → match_colors.py の NAMES に足して実行
  - お試し版（Cloudflare で公開中）は、まだ古い色のまま。次にお試し版を更新するときに反映される
  - 確認用：URL に `?hearts=5` を付けると、なかよし度をその数として動かせる（記録は変わらない）
  - 確認用リンク（Artifact）では URL に付けられないので、**設定画面の「確認用：なかよし度を切りかえて試す」**で切りかえる
    （記録は変わらない・開き直すと元に戻る）。`config.js` の `testHearts: true` で表示。**本番公開の前に false にする**
- **さわる場所の案内文は出さない（2026-10-26）**：遊ぶ画面の下の「頭・むね・おなか・しっぽをさわってね」は本編では非表示
  （どこが反応するかを自分で探してもらう方針）。お試し版では表示したまま（style.css の `body:not(.demo) .hint`）
- **なでなでレポート（2026-10-26）**：本編で X に広めてもらう仕組み。設定は `config.js` の `report`
  - 遊ぶ画面の下に、グレーの葉っぱが10枚（目立たない程度）。さわるごとに1枚ずつ緑に → 10枚でレポートが出る
  - 数えるのは「アプリを開いてから（前のレポートのあとから）」さわった回数。レポートを閉じると0から
  - レポート：なかよし○日目＋ハート、場所ごとの回数（あたま・むね・おなか・しっぽ）、**「？？？」は回数を出さず「ひみつ」**（さわっていれば ✨）
  - いちばん多くさわった場所で、タヌくんの絵とひとことが変わる（同じ数なら「いろんな所を…」と happy の絵）
  - ポスト文：なかよし○日目、場所ごとの 🟧 の数、？？？は ❓、ひとこと、#タヌくん。**本編の URL は公開したら `report.url` に入れる**
  - 共有ボタン（X でポスト・アプリでシェア・コピー）は、お試し版の診断と共通の関数にした
- **実績**：今は記録の一覧のみ（バッジは未実装。記録は取っているので後から作っても過去分が反映される）
- **設定**：呼び名の変更、ホーム画面追加の案内、記録のリセット（2回押しで確定）
- PC でファイルを直接開くと（file://）、メッシュ変形が使えないため、簡易方式（重ね絵の拡大）に自動で切り替わる

## 4. お試し版（X から開いてもらう体験版）

- 公開URL：**https://tanukun-demo.pages.dev/**
- 頭なで（とろける）とおなかぽんぽこ **だけ**（胸・しっぽは本編のお楽しみとして外した）
- 名前入力・何日目・なかよし度はなし。開いたらすぐ遊べる。回数制限なし
- **5回さわると「🔮 診断する」**。結果4種類（上から優先）：
  1. やりすぎ注意報（怒らせた）
  2. とろけさせ名人（とろけ2回以上）
  3. ぽんぽこ職人（おなか > 頭）
  4. なでなで上手（それ以外）
- 結果画面：「𝕏 でポストする」「📤 アプリでシェア」（対応スマホのみ）「📋 文章をコピー」「🔔 @Conchan_AIart をフォローして待つ」「もう一回あそぶ」
  - 結果を閉じると診断はリセット。2回目からは「🎉 結果が変わったよ！（前回は〜）」と前回と比較
  - ハッシュタグ **#タヌくん は本文に直接入れる**（X アプリが `hashtags=` 指定を消したため）
- X に URL を貼ると、カードの絵が出る（入り口用 `og/main.png`、結果ごと `og/<結果>.png`）。結果ポストは `r/<結果>.html` を経由するので、カードの絵が結果に合わせて変わる
- **実機で確認済み**：X アプリ内で遊べる／ポストできる／結果のカードの絵が出る／#タヌくん が入る

### 公開・更新の手順（Cloudflare Pages）
1. `python3 tools/build_demo.py --font <日本語フォント>` → `tanukun/demo-dist/` ができる
   - カードの絵のフォントは **M PLUS Rounded 1c ExtraBold**（オープンライセンス）を使用。
     取得元：`https://raw.githubusercontent.com/google/fonts/main/ofl/mplusrounded1c/MPLUSRounded1c-ExtraBold.ttf`
     （リポジトリには入れていない）
   - `images/happy.webp` は使っていないので、zip からは外している
2. `demo-dist` の中身を zip にする（zip 直下に index.html が来るように）→ ユーザーに渡す
3. ユーザーが Cloudflare で更新：
   https://dash.cloudflare.com/?to=/:account/pages/view/tanukun-demo を開く
   →「Create deployment」→ **Production** のまま zip をアップロード →「Save and deploy」
   - Workers & Pages の一覧にプロジェクトが表示されないことがあるため、上の直接リンクを使う
   - 新規作成時は「Continue to Pages」（従来の Pages）経由で作成した。Workers 経由だと URL にアカウント由来の文字が入るため避けた
- Cloudflare アカウントは、大学と無関係のメールアドレス（Google ログイン）で作成済み
- ※ このチャットの作業環境からは、外部サイトへの接続が制限されていて、公開ページを直接開けなかった。確認はユーザーの画面で行った

## 5. 決まったこと・方針

- 最終的な目的は **収益化**。まずは「続けて開いてもらえるか（継続率）」を確かめる段階
- 当面は **Web アプリ（PWA）** で進める。ストア版（Capacitor など）は手ごたえが出てから
- **アラーム機能は見送り**（Web では閉じているときに確実に鳴らせないため）
- 「何日目」は **累計を大きく・連続を小さく**（連続が途切れても「おかえり」で迎える）
- ログインなし。記録はブラウザ内保存（引き継ぎコードは、使う人が出てから検討）
- 本編の一般公開は、完成してから考える（お試し版だけ先に公開済み）

### ハートの貯まり方を見えるように（2026-10-26 実装済み）
- 右上（メニューでは「遊ぶ」の横）のハートを絵にして、**次のハートが下から少しずつピンクに満ちていく**（少し大きく、ふんわり光る）
- さわってポイントが入ると、**さわった場所から「+1」のハートが右上へ飛んでいく** → 届くとハートがドクン
- ハートが満タンになると「💖 ハートをゲット！」＋何が変わったか（`friendship.rewards`。ひみつ感を残した書き方）
- その日はじめて開くと「来てくれてありがとう！ 💗+10」
