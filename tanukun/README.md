# タヌくん スマホ版（試作①）

スマホのブラウザで動く「さわって楽しいか」確認用の最小版です。サーバー不要・外部サービス不使用。

## ファイルの役割

| ファイル | 中身 | ふだん触る？ |
|---|---|---|
| `config.js` | 絵のファイル名、タップ範囲、怒るまでの回数、隠れる秒数など | ◎ |
| `lines.js` | セリフ集（1行＝1セリフ） | ◎ |
| `images/` | 絵（Windows版の絵を背景透過・WebP形式に変換したもの） | ◎ |
| `app.js` | 動きのプログラム本体 | ほぼ不要 |
| `index.html` / `style.css` | 画面の骨組み・見た目 | ほぼ不要 |
| `manifest.webmanifest` / `sw.js` | ホーム画面に追加するための設定（PWA） | 不要 |

## 試し方

- **PCで**：`index.html` をダブルクリックしてブラウザで開くだけ。
  Chrome なら F12 → 左上のスマホアイコンでスマホ画面を再現できます。
- **スマホで**：ネット上に置いて URL を開くのが一番かんたんです（例：GitHub Pages）。
  ホーム画面への追加・オフライン動作は、この「ネット上に置いた」場合だけ有効です
  （ファイルを直接開く方式ではスマホの仕組み上はたらきません）。
- タップ範囲を確認したいときは URL の最後に `?zones` を付けます（例：`index.html?zones`）。

## いまの絵の割り当て

| 場面 | 使っている絵 |
|---|---|
| 通常 | normal（通常） |
| 照れ | shy（照れ顔） |
| 困り | troubled（困り顔） |
| とろけ | melt（とろけ顔） |
| おなかタップ | ponpoko1 ⇔ ponpoko2 を交互に（照れ中は muni） |
| 怒り | angry（怒り顔） |
| 茂み | bush（茂み・横幅を合わせて縮小して配置） |

## 絵の差し替え

1. 絵を `images/` に入れる（PNG 推奨・背景透明・**5枚とも同じ縦横サイズ**、縦長 4:5 が目安）
2. `config.js` の `images` のファイル名を書き換える（例：`'images/normal.png'`）
3. `?zones` を付けて開き、頭・おなか・しっぽの範囲がずれていたら `config.js` の `zones` を調整
4. （ネット上に置いた場合）`sw.js` の一覧のファイル名も新しいものに合わせる

## セリフの追加

`lines.js` に1行足すだけです。書き方はファイル冒頭の説明を参照してください。
新しい条件（例：天気）を足すときは、`app.js` の `MATCHERS` と `getContext()` に1行ずつ追加します。
