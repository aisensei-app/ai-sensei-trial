# タヌくん スマホ版（試作①）

スマホのブラウザで動く「さわって楽しいか」確認用の最小版です。サーバー不要・外部サービス不使用。

## ファイルの役割

| ファイル | 中身 | ふだん触る？ |
|---|---|---|
| `config.js` | 絵のファイル名、さわる範囲（頭・むね左右・おなか・しっぽ）、怒るまでの回数、隠れる秒数など | ◎ |
| `lines.js` | セリフ集（1行＝1セリフ） | ◎ |
| `save.js` | 記録（何日目・なかよし度・遊んだ回数）の保存 | ほぼ不要 |
| `demo.js` | お試し版の設定（診断結果の種類・ポストの文章など） | ◯ |
| `tools/build_demo.py` | お試し版をつくるプログラム | 不要 |
| `tools/build_preview.py` | 確認用リンク（1ファイル版）をつくるプログラム | 不要 |
| `HANDOFF.md` | 引き継ぎメモ（これまでの経緯・決まったこと・次にやること） | ◯ |
| `belly.js` | おなか・むねの「ぷるん」（網目の変形とばねの計算） | ほぼ不要 |
| `images/` | 絵（Windows版の絵を背景透過・WebP形式に変換したもの） | ◎ |
| `app.js` | 動きのプログラム本体 | ほぼ不要 |
| `index.html` / `style.css` | 画面の骨組み・見た目 | ほぼ不要 |
| `manifest.webmanifest` / `sw.js` | ホーム画面に追加するための設定（PWA） | 不要 |

## 試し方

- **PCで**：`index.html` をダブルクリックしてブラウザで開くだけ。
  Chrome なら F12 → 左上のスマホアイコンでスマホ画面を再現できます。
- **スマホで**：ネット上に置いて URL を開くのが一番かんたんです（例：GitHub Pages）。
  ホーム画面への追加・オフライン動作は、この「ネット上に置いた」場合だけ有効です
  （ファイルを直接開く方式ではスマホの仕組み上はたらきません）。
- タップ範囲を確認したいときは URL の最後に `?zones` を付けます（例：`index.html?zones`）。

## 画面の流れ

0. **はじめて開いたとき**：タヌくんが「なんて呼んだらいい？」と聞きます（「あとできめる」で飛ばせます。設定からいつでも変更可）。
1. **メニュー画面**：「なかよし ○日目」（のべ日数）と、2日以上続いていれば「れんぞく ○日」を表示。
   タヌくんが来かた（はじめて／毎日／ひさしぶり）や時間帯に合わせてあいさつします。
2. **遊ぶ**（ボタンの横のハート💖＝なかよし度）：タップで遊ぶ画面へ。左上「もどる」でメニューへ。
3. **実績**：いまは記録の一覧（なでた回数・セリフ図鑑など）。バッジは次の段階。
4. **設定**：ホーム画面に追加する方法の案内、記録のリセット。

## 記録（何日目・なかよし度）のしくみ

- 記録はスマホのブラウザの中だけに保存します（サーバー不要・ログインなし）。
- 日付は **午前4時** に切り替わります（`config.js` の `days`）。
- なかよしポイント：その日はじめて来ると +10、タップ1回で +1（1日20まで）。
  ポイントがたまるとハートが増えます（`config.js` の `friendship`）。
- 日付をまたぐ動きの確認：URL の最後に `?today=2026-11-03` のように付けると、その日に開いたことになります。
- ※ ブラウザのデータを消すと記録も消えます。iPhone の Safari はしばらく開かないと消すことがあるため、
  「ホーム画面に追加」して使うのがおすすめです。

## おなか・むねの「ぷるん」（Windows版と同じ方式）

- **おなか・左のむね・右のむね**の3か所を、それぞれさわって揺らせます（むねはおなかの45%の控えめな揺れ）。
- むねは「肉のかたまりが上下にぷるんぷるん揺れる」動きです。動きの中心は乳輪あたり、動く範囲は胸のふくらみ全体（ふちほど弱い）。揺れの大きさは `chestJiggle.bob`。
- 絵を網目のように変形させて（メッシュ変形）、さわった場所だけを変形させます。
  変形は楕円の中心ほど強く、ふちに向かってなめらかに 0 になるので、境目ができません（`belly.js`）。
- 動きは「ばね」の計算です（Windows版と同じ数値：ばねの強さ 450、止まりやすさ 9）。
  - **指を置いている間**：その場所がへこみ、指の位置がくぼんで、うっすら影がつく（押した感）
  - **指をはなす**：しっかり押していたら「ぷるん」と強めに戻る。ちょんと触っただけなら、Windows版と同じく約8%へこんで約4%ふくらみ、約0.8秒で止まる。連打すると揺れが足し算される
  - **指をすべらせる**：おなかを引っぱれる。はなすと、半分ずつ行きすぎながら約1秒で戻る
    （胸は小さい範囲を引っぱると形がくずれるため、引っぱらずに「ぷるん」だけ。`chestJiggle.drag` で切りかえ）
  - おなかは、タップした場所から「ぽん！」「ぽこ！」の文字（1秒以内に続けると交互）
- 数値は `config.js` の `bellyJiggle` / `chestJiggle` / `bellyWords` で調整できます（`strength: 0.5` で半分の揺れ）。
- ※ PC でファイルを直接開いたとき（file://）は、ブラウザの安全のしくみで網目の変形が使えないため、
  おなかだけ、かんたんな方式（重ね絵を拡大）に自動で切り替わります。ネット上に置けば本来の方式になります。
- ※ 絵を差し替えて位置が変わったら、各楕円の `x`・`y`（中心）と `rx`・`ry`（半径）、`zones`（さわる範囲）を合わせてください。

## 絵の差し替え

1. 絵を `images/` に入れる（PNG 推奨・背景透明・**5枚とも同じ縦横サイズ**、縦長 4:5 が目安）
2. `config.js` の `images` のファイル名を書き換える（例：`'images/normal.png'`）
3. `?zones` を付けて開き、頭・おなか・しっぽの範囲がずれていたら `config.js` の `zones` を調整
4. （ネット上に置いた場合）`sw.js` の一覧のファイル名も新しいものに合わせる

## セリフの追加

`lines.js` に1行足すだけです。書き方はファイル冒頭の説明を参照してください。
`{name}` と書くとそこが呼び名になり、名前なしのときは「{name}、」ごと消えます（例：「{name}、おかえり〜」→「おかえり〜」）。
新しい条件（例：天気）を足すときは、`app.js` の `MATCHERS` と `getContext()` に1行ずつ追加します。

## お試し版（X から開いてもらう体験版）

- 頭なで（とろける）と、おなかぽんぽこ だけ。名前入力・何日目・なかよし度はなし。開いたらすぐ遊べます。
- 5回さわると「🔮 診断する」ができるようになり、遊び方から結果が決まります
  （やりすぎ注意報／とろけさせ名人／ぽんぽこ職人／なでなで上手）。結果は「𝕏 でポストする」で投稿できます。
  ログイン画面が出てしまう場合に備えて、「📤 アプリでシェア」（スマホの共有メニューから X アプリで投稿）と「📋 文章をコピー」もあります。
- 結果を閉じる（「もう一回あそぶ」）と診断はリセットされ、また5回さわると新しく診断できます。2回目からは「🎉 結果が変わったよ！（前回は〜）」のように前回とくらべて表示します。
- 結果画面の下に「🔔 @アカウント をフォローして待つ」ボタン（`demo.js` の `followId`）。
- 結果の種類・文章・ポストの文は `demo.js` で変えられます。

### 更新のしかた
1. tanukun フォルダで次を実行すると、`demo-dist` フォルダができます
   ```
   python3 tools/build_demo.py
   ```
   （カードの絵の文字に日本語フォントが必要です。`--font` で指定。なければ自動で探します）
2. `demo-dist` の中身を zip にまとめます（zip の中にフォルダを作らず、index.html がいちばん上に来るように）
3. Cloudflare の画面で、次のリンクからプロジェクトを開きます（一覧に出ないことがあるため）
   https://dash.cloudflare.com/?to=/:account/pages/view/tanukun-demo
4. 「Create deployment」→ **Production** のまま zip をアップロード →「Save and deploy」
5. スマホで開き直して確認（古い版が出たら再読み込み）
