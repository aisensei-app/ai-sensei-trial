# 📮 お手紙の Google フォームのつなぎ方

タヌくんのポストで書いたお手紙を、Google フォーム（の回答のスプレッドシート）に届けるための手順です。
**「事前入力した URL」を1つもらえば、あとは Claude が config.js に貼るだけ**でつながります（2026-11-03〜）。

## 1. フォームを作る（ユーザー）
1. Google フォームで新しいフォーム（題名は何でもよい。例「タヌくんへのお手紙」）
2. 質問を **この順番で3つ**（どれも「必須」にしない）
   | 順番 | 質問の名前 | 種類 |
   |---|---|---|
   | 1 | お手紙 | 段落 |
   | 2 | 切手 | 記述式 |
   | 3 | 言語 | 記述式 |
3. 設定 → 回答
   - **メールアドレスを収集しない**
   - **「ログインが必要」系はすべてオフ**（回答を1回に制限、など）← オンだとアプリから送れない
4. 回答 → スプレッドシートにリンク（あとで Claude が集計に読むため）

## 2. 「事前入力した URL」を取る（ユーザー）
1. 右上の︙ →「事前入力した URL を取得」
2. お手紙に `text`、切手に `stamp`、言語に `lang` と打つ
3. 「リンクを取得」→「リンクをコピー」→ チャットに貼る
   - 長い URL（`https://docs.google.com/forms/d/e/…/viewform?usp=pp_url&entry.…`）を使う。短い forms.gle のリンクは使えない

## 3. つなぐ（Claude）
- config.js の `post.form.prefill` に、もらった URL を貼る（app.js の readPrefill が、送り先と質問の番号を読む）
- 確認：scratchpad の playwright で、お手紙を送ると `formResponse` に `entry.〇〇=お手紙の文` が出るか（page.route で横取りして見る）。
  本物のフォームにも1通テストを送り、スプレッドシートに入るかユーザーと確かめる（テストの行は消してもらう）
- sw.js の CACHE の番号を上げて、公開用 zip を作り直す
- つながると、自動で次のように変わる
  - お手紙を書く画面の注意書き：「Google フォームを通じて作者に とどき、作者と、集計を手伝う AI が読みます…」
  - はじめてのお知らせ：📮 の1行が足される（notice.post）
  - ⓘ お約束と注意：「お手紙について」が送る版になり、「🔒 Google のサービス」が出る

## 注意
- **お手紙の中身は、このリポジトリ（公開）に書かない**。集計のレポートも非公開の場所に
- 届いたかどうかはアプリからは確かめられない（no-cors で送るため）。届かなくても、お手紙はスマホの中には残る
