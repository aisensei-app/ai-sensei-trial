## 使い方
### ChatGPT
1. 新しいチャットで **設定画** と **images/normal.webp（通常の絵）** を添付
2. 「① 共通の説明」は `pon/ILLUST_PROMPTS.md` の **① をそのまま** 送る（タヌくんの特徴・手の注意。1回だけ）
3. U2 → U3 の順に1枚ずつ送る（構図の説明が返ってきたら「OK、描いてください」）
4. U1（貝だけ）は **別のチャット** で送る（タヌくんの説明が混ざらない方がきれいに出ます）

### Gemini（画像生成。Nano Banana と呼ばれる機能）
- Gemini は「OK を待って」が効かず、すぐ描くことが多いので、**1回で全部伝える** 短めの文にしています（下の「Gemini 版」）
- 縦横の比率が守られないことがある → 守られなかったら「縦長 2:3 にして。ほかはそのまま」と追いかけて頼む
- 画面のはし（特に右下）に目印のマークが入ることがある → **キャラクターや貝は、はしから十分はなして** と頼んでいます
- 届いた絵の背景がマゼンタ1色でない（グラデーションなど）ときは、下の「追いプロンプト」を使う

## U1 貝がらのまとめ絵（ChatGPT・Gemini 共通）
```
スマホゲームで使う「貝がら」のイラストを8個、1枚の絵にまとめて描いてください。
占いのゲームで、閉じた貝をタップすると「ぱかっ」と開く演出に使います。

【画面】
・横長 3:2（1536×1024 くらい）
・背景は、完全に均一な蛍光マゼンタ（#FF00FF）の単色。グラデーション・模様・ノイズ・影・光のにじみは入れない（あとで背景を抜くため）
・8個を2段に並べる：上の段に「閉じた貝」4個、下の段に「開いた貝」4個。
　下の段の貝は、それぞれ真上の貝が開いたもの（同じ色・同じ形・同じ大きさ）
・どれも重ならず、たがいに、また画面のはしとも十分にはなす（まわりにたっぷり余白）

【4種類の貝（左から順に）】
1. コーラル色（サーモンオレンジ）の、ホタテのような扇形の貝
2. クリーム色〜真珠色の、扇形の貝（ふちがほんのり虹色）
3. 空色〜ターコイズの、扇形の貝
4. 金色の、扇形の貝（つやのある光沢。白いキラキラを2〜3個）※特別な当たりの貝
・4つとも同じ形・同じ大きさ。正面より少し上から見た向き

【開いた貝（下の段）】
・上下2枚の殻が、ちょうつがいで60度くらい開いている
・中は、やわらかく光る白〜うすい金色。まんなかに、つやのある白い真珠が1粒（金の貝だけは金色の真珠）
・中から小さなキラキラが2〜3個

【タッチ】
・かわいいゲームアイテム風。やわらかいパステル調、細いこげ茶のふちどり、ほんのり陰影
・文字・ラベル・数字・手・人物・背景のものは描かない

【注意】
・マゼンタ（蛍光ピンク）や紫に近い色は、背景以外では使わない（ピンク系の貝にしない）
・絵のふちをぼかさず、背景との境目をくっきりさせる
```
> Gemini のときは、最後に「1回で仕上げてください。説明は不要です」と1行足す

## うまくいかないときの追いプロンプト
- 背景が単色でない → 「背景を、完全に均一な #FF00FF の単色にして。影・グラデーション・ノイズは全部なくして。ほかはそのまま」
- 貝がピンク・紫っぽい → 「◯番の貝の色を、マゼンタや紫から遠い色（コーラルオレンジ）にして。ほかはそのまま」
- 開いた貝と閉じた貝の形・大きさがちがう → 「下の段の貝を、真上の貝と同じ形・同じ大きさにそろえて。ほかはそのまま」
- 手・指が崩れた → `pon/ILLUST_PROMPTS.md` の「③ 直してもらうときの文」
- 縦横の比率がちがう（Gemini）→ 「縦長 2:3 にして。ほかはそのまま」
