# ぽんぽこリズム イラストのプロンプト（ChatGPT 用）

## 使い方
1. ChatGPT で **新しいチャット** を開き、**設定画** と **「通常」の絵（images/normal.webp）** を添付する
2. 最初に「① 共通の説明」を送る（キャラクターの説明。1回だけ）
3. 続けて、描いてほしい絵のプロンプト（A1 など）を **1枚ずつ** 送る
4. ChatGPT が「構図の確認」を文章で返してくるので、よければ「OK、描いてください」と送る
5. できた絵の **手と指を確認** する。崩れていたら「③ 直してもらうときの文」を使う

> 💡 コツ
> - 1つのチャットで描く枚数は、**4〜5枚まで** にすると、キャラクターがぶれにくいです（長くなると、だんだん似なくなります）
> - 気に入った1枚ができたら、次の絵のときに **その絵も添付** して「この絵と同じタヌくんで」と伝えると、そろいやすくなります
> - 文字・サイン・ロゴは、**絵の中に入れない** ように頼んでいます（文字は、あとでこちらで入れます）

## ① 共通の説明（最初に1回だけ送る）

```

添付した設定画と「通常」の絵のキャラクター「タヌくん」を、毎回まったく同じキャラクターとして描いてください。
1枚ずつ、ていねいに仕上げてほしいので、急がず、細かいところまで確認しながら描いてください。

【タヌくんの特徴（毎回かならず守ってください）】
・タヌキの獣人の男の子。ぽっちゃり体型で、まるくて大きなおなかが一番の魅力
・毛の色：あたたかい茶色。おなかはそれより明るい、やわらかい肌色寄りの茶色
・頭：銀色がかった白いボサボサの髪。丸い耳（ふちと内側が濃い茶色）
・顔：目のまわりに、タヌキらしい濃い茶色の模様。目は琥珀色。小さな黒い鼻。口は「ω」の形
　ほっぺに白い弧のペイント
・体：白いボディペイント（肩に同心円のうず、腕と脚にしま模様、ところどころに白い点）
・首：白い牙のネックレス（茶色と赤茶色の玉を通したひも）
・腰：緑の葉っぱの腰みの。編んだ縄のベルト。腰みのは、どの絵でもかならず着けたまま
・しっぽ：ふさふさで太い。茶色に濃い茶色の帯、先がクリーム色
・手：体より濃い茶色のケモノの手。指は太く短くて丸みがあり、爪は見えない。
　手のひらに小さな肉球。親指をふくめて、片手に5本の指
・足：濃い茶色のケモノの足

【絵のタッチ】
・日本のアニメ・ゲームのイラスト調。やわらかい厚塗りで、毛並みはふんわり、おなかはつやっと丸く
・あたたかい色合い。設定画と同じ色味・同じ線の太さ
・かわいく、親しみやすい表情。健全な内容にしてください（SNS でシェアされる絵です）

【手と指について（とても大事です）】
・手と指は崩れやすいので、特にていねいに描いてください
・片手の指は、親指をふくめて5本。指がくっついたり、増えたり、ねじれたりしないように
・指をたくさん広げるポーズは避けて、「にぎる」「そえる」「グー」など、指がまとまるポーズにしてください
・描き終えたら、手と指の数・形・向きを見直して、おかしいところがあれば直してから仕上げてください

【毎回守ってほしいこと】
・文字、ロゴ、サイン、透かしは入れない
・キャラクターは1人だけ（ほかの人物やキャラクターの手は入れない。指定したとき以外）
・描く前に、まず「構図・ポーズ・手の形・背景」を短い文章で説明して、私の OK を待ってください

理解できたら「了解しました」とだけ返してください。
```

## ③ 直してもらうときの文

### 手や指が崩れたとき
```
とてもよく描けています。ただ、【右手／左手】の指が【多い／くっついている／ねじれている】ので、そこだけ直してください。
・絵のほかの部分（顔・体・背景・色・構図）は、いっさい変えないでください
・手は、体より濃い茶色のケモノの手。太く短い指で、親指をふくめて5本。爪は見えない
・【ポーズ（例：ばちをにぎる／手のひらをおなかに当てる）】の形で、指の向きと重なりを自然に
・直したら、指の数をもう一度数えて確認してから仕上げてください
```

### キャラクターが似ていないとき
```
タヌくんの【髪の色／顔の模様／ボディペイント／しっぽの色】が設定画とちがっています。
添付の設定画と「通常」の絵に合わせて、そこだけ直してください。ポーズ・構図・背景は変えないでください。
```

### 色味が本編とちがうとき
```
タヌくんの毛の色が【明るすぎ／赤すぎ／くすんでいる】ので、添付の「通常」の絵と同じ、あたたかい茶色に合わせてください。
ほかの部分は変えないでください。
```
