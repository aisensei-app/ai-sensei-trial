# 洗うゲーム：図鑑の追加の小物（ChatGPT 用プロンプト）

目的：落としものの図鑑を 5種 → 12種にする（ZUKAN に1行ずつ足す）。いまの絵は `washing/art/items_src.png`（添付して「同じタッチで」と頼む）。

## プロンプト（そのままコピー）

添付の絵（貝がら・ヒトデ・コンブなど）と同じタッチで、ゲームに使う「小物のイラスト」を7個、1枚の絵にまとめて描いてください。

【画面】
- 横長 3:2（1536×1024 くらい）。
- 背景は、完全に均一な蛍光マゼンタ（#FF00FF）の単色。グラデーション・模様・ノイズ・影・光のにじみは入れない（あとで背景を抜くため）。
- 7個を2段に並べる：上の段に4個、下の段に3個。どれも重ならず、ほかの絵とも画面のはしとも十分にはなす（まわりに余白）。順番は左から右、上の段から下の段へ、下に書いた番号順。

【タッチ】
- かわいいゲームアイテム風。やわらかいパステル調の色、細い茶色のふちどり、ほんのり陰影。添付の絵と同じ線の太さ・塗り方・大きさ感。
- 1個ずつ、斜め上から見た1つだけの絵。文字・ラベル・数字・手・体・背景のものは描かない。

【7個（番号順）】
1. うにのから：うすい灰緑〜ベージュの、丸くて小さなトゲトゲの跡がある殻。ほんの少しだけ紫がかってもよいが、鮮やかな紫・ピンクにはしない。
2. さんごのかけら：オレンジがかったコーラル色（朱赤〜サーモン）の、枝分かれした小さなさんご。マゼンタに近いピンクは使わない。
3. ハイビスカスの花びら：赤〜朱色の、ぬれたようなつやのある花びら1枚（しずくを1つ）。マゼンタに近い色は使わない。
4. シーグラス：丸くすりへった、すりガラスのような青緑と淡い水色のガラスのかけらを2つ。
5. ヤドカリ：うずまきの貝がらを背負った、ちいさな、かわいいヤドカリ（目は小さな黒い点、はさみは小さく。リアルすぎない）。
6. 真珠：つやのある白いまるい真珠1粒と、右上に小さなキラキラ。（貝は描かない）
7. 金のヒトデ：添付のピンクのヒトデと同じ形・同じ大きさの、金色のヒトデ（光沢、白いキラキラを2〜3個）。

【注意】
- 全体を通して、マゼンタ（蛍光ピンク）に近い色は、背景以外では使わない。
- 絵のふちをぼかさず、背景との境目をくっきりさせる。

## うまくいかないときの追いプロンプト
- 背景が単色でない → 「背景を、完全に均一な #FF00FF の単色にして。影・グラデーション・ノイズは全部なくして。ほかはそのまま」
- 重なっている・近すぎる → 「各アイテムの間隔を2倍に広げて。ほかはそのまま」
- 1個だけ直したい → 「3番（ハイビスカスの花びら）だけ、〇〇に直して。ほかは一切変えないで」
