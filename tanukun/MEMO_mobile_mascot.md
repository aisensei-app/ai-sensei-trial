# 相談メモ：スマホの画面にタヌくんが出てくるアプリ（デスクトップ版の考え方をスマホへ）

作成：2026-11-01（スマホ版タヌくんのチャットで作成。別のプロジェクト「ウシくんクマくん デスクトップアプリ」のチャットに持っていって相談するためのメモ）

---

## 1. きっかけ
- 先々週ごろ、X に「デスクトップの上にタヌくんがいて、お腹をポンポンしている」動画を投稿した
- 2026-11-01、X で1件の要望：「**これをデバイス（スマホ）で使えるようにしてほしい**」
- つまり、**スマホの画面の上にタヌくんが出てくる**もの

## 2. いまある2つのプロジェクト
| | スマホ版タヌくん（Webアプリ） | ウシくんクマくん（デスクトップアプリ） |
|---|---|---|
| 場所 | GitHub `aisensei-app/ai-sensei-trial` の `tanukun/` | パソコンの中の `kopin-home`（GitHub にはない） |
| 中身 | なでる・おなかぽよん・セリフ・思い出・ミニゲーム・3言語（日本語・英語・簡体字） | デスクトップの上にキャラクターがいる。キャラクターをタヌくんにも変えられる。OpenClaw・Codex を連携させて、自分で動く AI（エージェント）を作る構想 |
| 公開 | https://tanukun.pages.dev/（Cloudflare Pages。PWA＝ホーム画面に追加できる Web アプリ） | ― |
| 状況 | 公開中。訪問 約2,800回／日（10/31）。海外が半分以上。**Android が約6割** | （相談先のチャットで確認） |

## 3. やりたいこと（ユーザーの理想）
1. スマホの画面の上に、タヌくんが出てくる（ほかのアプリを使っている間も）
2. タヌくんの中身は ChatGPT や Claude で、**会話できる・チャットで相談できる**
3. **一緒に YouTube の画面を見られる**（タヌくんが横で反応する）

## 4. スマホでできること・できないこと（スマホ版のチャットで調べた見通し）
| やりたいこと | Android | iPhone（iOS） | 今の Web アプリ（PWA） |
|---|---|---|---|
| ほかのアプリの上にキャラクターを出す | **できる**（「ほかのアプリの上に重ねて表示」の許可。昔の Facebook のチャットの丸いアイコンと同じしくみ）。ただしアプリを作る必要があり、Google Play の審査はこの許可の使い方に厳しめ | **できない**（iOS は、ほかのアプリの上に描くことを許していない）。代わりに、ホーム画面・ロック画面のウィジェット、ダイナミックアイランドの小さな表示はできる（動きは少ない） | できない（アプリの中だけ） |
| タヌくんと AI で会話 | できる | できる | **できる** |
| 一緒に YouTube を見る | YouTube アプリの上にタヌくんを重ねられる | YouTube アプリの上は無理。アプリの中に YouTube を埋めこむ形なら可 | **アプリの中に YouTube を埋めこめばできる**（タヌくんが横で反応する） |

**AI で会話する部分の注意**
- ChatGPT や Claude を使うには、API キー（使うための鍵）が要る。鍵はアプリに入れられないので、**間に小さなサーバーが必要**（Cloudflare Workers などで作れる）
- 会話1回ごとに **API の利用料**がかかる → 無料で広く配ると費用がふくらむ。会話は有料（応援の特典）にする、回数に上限を付ける、などが必要
- 今のスマホ版は「記録はスマホの中だけ」と約束している。**会話の文はサーバーと AI の会社に送られる**ので、お知らせの文と、プライバシーの説明が必要
- タヌくんは「ちょっぴり大人向け」の表現があるので、AI の会話の内容の範囲（どこまで答えるか）を決めておく必要がある。各社の利用規約にも合わせる

## 5. 進め方の案（スマホ版のチャットでの考え）
| 案 | 中身 | 良い点 | 弱い点 |
|---|---|---|---|
| **A. 今の Web アプリに「いっしょモード」** | アプリの中で YouTube を一緒に見る・AI と話す | iPhone・Android の両方。今の公開のしかたのまま。いちばん早い | ほかのアプリの上には出られない（要望そのものではない） |
| **B. Android のアプリを作る** | ほかのアプリの上にタヌくんが出る（要望そのもの） | 要望どおり。訪問の約6割が Android | アプリ作り・Google Play の登録（約25ドル）と審査。iPhone はできない |
| **C. デスクトップ版をそのままスマホへ** | 別のプロジェクトのしくみを、スマホ向けに作り直す | 自分で動く AI の構想を生かせる | いちばん大がかり |

**スマホ版のチャットのおすすめ**：要望はまだ1件なので、いきなり B・C ではなく、
1. まず **A**（今のアプリの中で、YouTube を一緒に見る＋短い会話）を小さく作り、X で反応を見る
2. 反応が大きければ **B（Android）** に進む。そのとき、別のプロジェクトのタヌくんの動き・AI のしくみを使い回せるかを確かめる

## 6. 別のプロジェクトのチャットで、相談したいこと
1. デスクトップ版のタヌくん（絵・動き・おなかぽんぽん）は、どんなしくみで作っている？ スマホ（Android のアプリ・Web）で使い回せる部分はある？
2. OpenClaw・Codex を連携した「自分で動く AI」は、スマホのタヌくんにも入れられる？ そのとき、どこで動かす（パソコン・サーバー・スマホ）？ 費用は？
3. AI との会話の部分は、2つのプロジェクトで**共通の部品**にできる？（同じサーバー・同じキャラクター設定を使う）
4. 会話・YouTube を一緒に見る機能を、どちらのプロジェクトで先に作るのがよい？
5. タヌくんの「キャラクター設定」（口調・性格・言ってはいけないこと）を、両方で同じものにするには？

## 7. 決まっていること（スマホ版のチャットで、ユーザーと決めたこと）
- 1年後の目標：**タヌくんに毎日会いに来るファンが世界に1,000人**。収益はまず月3万円
- 売るのは AI の絵ではなく「**おなかをぽよんする体験**」。AI でたくさん絵を描けることを強みにして、AI でもいい人に届ける
- できるだけ自給自足（絵師さんへの依頼やスタンプは、いつか）
- タヌくんの活動は、所属先・本名と切り離す（StartX や大学は出さない）
- 次の大きなテーマは「7日目以降も来る理由」。今日、だれのものかわからない形で「何日目の人が来たか」を数える仕組みを入れた
